The Problem

Attendance runs on trust.
samaya runs on proof.

Register sign-ins get buddy-punched. Spreadsheets don't know where an employee actually was. Payroll gets built by hand from whatever the register says. samaya replaces all of it with one system: a face or fingerprint confirms who, GPS confirms where, and payroll builds itself from what actually happened — for one company or a hundred, from the same codebase.

System Overview

One backend.
Four surfaces.

A single multi-tenant API drives every surface. Every table is scoped by companyId; a kiosk authenticates with its own device key, never a user token; and one shared attendance-resolution function is the only place check-in vs. check-out gets decided — called identically from the mobile app, the kiosk's face path, and the kiosk's fingerprint path.
